# 프레임워크 세부 작성 규칙 (Phase B 착수 시 로드)

## 1. WBS·CPM 운용 규칙 (프로젝트 관리자)

### 1-1. WBS 분해

- 분해 계층: 과제 → 실행 과업(Work Package) → (정식 모드 한정) 세부 활동
- 과업 단위 기준: 단일 R 지정 가능 + 산출물 1개 이상 정의 가능한 크기
- 각 과업 필수 속성: 산출물 / 선행 과업 / 기간 범위 [추정] / 담당(R)
- **선결 과업 규칙**: P4 conditional_pool의 이행 조건은 해당 과제 WBS
  최상단에 [선결] 태그로 배치 — 미완료 시 후속 착수 불가 관계 명시

### 1-2. 의존관계·임계 경로

- 의존 표기: "과업A → 과업B" (텍스트만, 도식 금지)
- 의존 유형은 FS(선행 완료 후 착수)를 기본으로 하고, 병행 가능(SS)은
  괄호 표기
- **임계 경로**: 지연 시 전체 일정이 밀리는 과업 연쇄를 식별하여
  "[임계]" 태그 — 임계 과업에는 지연 트리거·대응 경로 필수 부여
- 기간 산정: 범위 표기(예: "2~3개월 [추정]") + 산정 논리 1줄.
  근거 없는 단일 확정치 금지
- 순환 의존(A→B→A) 발견 시 과업 재분해로 해소 후 이력 기록

### 1-3. 구간 배치 (계획 지평 비례)

- Quick-Win(초반 ~20%): 저자원·고가시성 과업 우선 — 초기 동력 확보
- 본궤도(중반): 임계 경로 중심 배치, 자원 경합 과제의 시간축 분산
- 안착·고도화(후반): 성과 측정·제도화·확산 과업
- 기관 고정 일정(이사회, 성과평가 실적 마감, 예산 편성)과 마일스톤
  충돌 회피 — 승인 필요 과업은 이사회·위원회 개최 시점에 역산 배치

## 2. RACI 운용 규칙 (R&R 조정관)

### 2-1. 표준 규칙 (오용 방지)

- **A(Accountable)**: 과업당 반드시 1인(1기능) — 복수 지정 금지.
  복수가 불가피해 보이면 과업을 분할
- **R(Responsible)**: 공백 금지. "관계 부서 협조"류의 무주공산 표기 금지
- **C(Consulted)**: 쌍방향 협의 대상만 — 5개 초과 시 과다 지정 경고
  (협의 남발은 지연·책임 희석 요인)
- **I(Informed)**: 단방향 통보 대상 — 보고 라인과 중복 시 정리
- 동일인(기능)이 R과 A를 겸하는 것은 소규모 과업만 허용, 사유 표기

### 2-2. 담당 표기 원칙

- 조직도 제공 시: 실제 부서명 사용 (직위·인명은 사용자 명시 시에만)
- 미제공 시: 기능 역할 명칭 — [기획 기능] [재무 기능] [인사 기능]
  [정보화 기능] [현업 기능] [대외협력 기능] 등 + [가정] 라벨
- **부하 집중 점검**: 동일 R에 동시기(같은 분기) 과업 3개 이상 배정 시
  플래그 → 시간축 분산 또는 R 분담 조정, 조정 이력 기록

## 3. KPI Cascade 운용 규칙 (성과 설계자)

### 3-1. 승계 원칙 (이중 지표 체계 방지)

- 유일 원천: Phase 2 KR — 과제 KPI는 KR의 하향 분해로만 생성
- 연결 표기 필수: "KR1-1(병상가동률 ○%) → 과제 KPI(○○ 프로세스
  적용률)" 형식으로 상향 기여 경로 명시
- KR 미연계 지표 신설 시: [신규] 라벨 + 필요 근거 1줄 + P2 목표 체계
  개정 필요 여부 표기
- 하나의 KR에 다수 과제가 기여하는 경우: 과제별 기여 몫(분담 목표치)을
  설정하여 합산이 KR 목표치와 정합하도록 배분

### 3-2. 지표 유형 이원화

- **실행률(activity)**: 착수·완료·보급률 등 — 진도 관리용
- **성과(outcome)**: KR 직결 결과 지표 — 목표 달성 판정용
- 과제당 최소 outcome 1개 필수 — activity 일변도 구성은 실격
- 각 KPI 필수 속성: 산식 / 데이터 원천 / 기준선(미확보 시 [가정] +
  확보 방법) / 목표치 / 측정 주기 / 측정 책임(R과 분리 권장)

### 3-3. 모니터링 설계

- 측정 주기와 보고 주기를 구분 (예: 월 측정 / 분기 보고)
- 신호등 기준 제시: 정상(목표 대비 ≥90%) / 주의(70~90%) / 경보(<70%)
  — 경보 시 대응 절차(원인 분석 → 계획 조정 보고) 1줄 명시
- 상위 평가 체계 연계 지표는 실적 마감 일정에 맞춘 중간 점검 시점 배치

## 4. 리스크·거버넌스 설계 규칙

- P4 판정표의 핵심 리스크 중 실행 단계 관련 건을 승계하여
  "리스크 워치리스트" 구성: [리스크 | 조기 신호 | 담당 | 대응 경로]
- 지연 트리거: 임계 과업의 마일스톤 미달 시 발동 조건과 에스컬레이션
  경로(R → A → 경영진) 명시
- 추진 체계 선택 기준: 부서 단독 수행 가능(자체 추진) / 2개 부서 이상
  상시 협업(기존 위원회) / 기관 전략급·신규 대규모(전담 TF)

## 5. 토론 시 관점별 대표 지적 유형 (참고)

- 프로젝트 관리자: "선결 과업 없이 본 과업이 먼저 배치됐다",
  "임계 경로 과업에 버퍼가 전혀 없다", "3개 과제가 같은 분기에
  동일 기능을 점유한다"
- R&R 조정관: "A가 2개 기능으로 지정돼 책임이 희석된다",
  "C가 7개 기능이라 협의만으로 한 분기가 소요된다",
  "노사협의 필요 과업인데 협의 일정이 없다"
- 성과 설계자: "전부 착수율·완료율뿐이고 outcome 지표가 없다",
  "이 KPI는 어느 KR에도 기여하지 않는 고아 지표다",
  "두 과제의 분담 목표치 합산이 KR 목표를 초과 계상한다"
