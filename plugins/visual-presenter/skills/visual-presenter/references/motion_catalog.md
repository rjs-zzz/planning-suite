# 모션 기법 카탈로그 (Motion Catalog)

사용자가 준 8개 분야 64종에 추가 추천 8종을 더했다. 기법마다 이 스킬로 어디까지 만들 수 있는지 등급을 붙였다.

## 구현 등급

| 등급 | 뜻 | 스킬이 하는 일 |
|---|---|---|
| **직접** | 단일 HTML 화면(도형·글자·선의 움직임)으로 바로 만들 수 있다 | 만든다 |
| **근사** | 화면에서 비슷하게 흉내 낼 수 있지만 품질에 한계가 있다 | 만들고 한계를 1줄 알린다 |
| **기획** | 촬영, 3D 제작 도구, 물리 연산, 현장 설비가 필요하다 | 만들 수 없음을 밝히고 구성안만 낸다 |

- 등급은 [설계]다. 실제로 만들어 본 결과로 고쳐 나간다.
- '쓰임새'가 —인 기법은 분석·기획 산출물에 쓸 일이 드물다. 사용자가 지정할 때만 다룬다.

## 이 카탈로그의 쓰임

- 기법을 고르는 표가 아니다. 움직임은 Phase B에서 찾은 실제 사례에서 출발한다.
- 이 카탈로그는 ① 검색어로 쓸 기법 이름, ② 구현 등급(직접·근사·기획) 판정에만 쓴다.

## 카탈로그를 넓히는 법

- 사용자가 새 기법을 추천해 달라고 하면 SKILL.md 「최신 동향 탐색 (디자인 레퍼런스)」 절차로 찾아 2~3개를 추천한다.
- 채택된 새 기법은 산출물 끝에 `○ 스킬 개선 후보`로 남기고, 월간 점검에서 이 카탈로그에 넣을지 정한다.
