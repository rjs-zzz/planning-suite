# 프레임워크 세부 작성 규칙 (Phase B 착수 시 로드)

## 1. PDCA 모니터링·시정 체계 (프로젝트 통제관)

### 1-1. P5 승계 원칙 (이중 체계 방지 — 엄수)

- Check 판정 기준 = P5 신호등(정상 ≥90% / 주의 70~90% / 경보 <70%)
- Act 발동 = P5 지연 트리거·에스컬레이션 경로(R → A → 경영진)의 확장
- 측정·보고 주기 = P5 governance 승계
- P6의 임무는 **공백 보강**: 판정 후 조치 프로토콜, 3층 평가, 협의체
  운영 규칙 등 P5가 정의하지 않은 부분만 신규 설계
- 승계 항목 변경 시: 변경 사유 1줄 + 원안 병기 (무단 대체 금지)

### 1-2. 3층 평가 체계

- **상시 모니터링**: KPI 측정 주기 단위 — 신호등 판정, 담당(R) 자체 수행
- **중간 평가**: 마일스톤 도달 시 — 협의체 심의, AAR 기록 의무
- **최종 평가**: 계획 종료 시 — 목표 대비 종합 판정, 차기 사이클 인계
- 공공기관 안건: 경영평가 실적 마감·이사회 보고 일정에 중간 평가를
  역산 배치 (평가 직전 몰아치기 방지 — 최소 1개 분기 선행)

### 1-3. Act 시정 프로토콜 (판정별 조치)

- **정상**: 기록만 — 추가 보고 생략 (과잉 통제 방지)
- **주의**: 담당(R) 원인 분석 1주 내 → 계획 내 조정안 A에게 보고
- **경보**: 즉시 에스컬레이션 → 협의체 소집 → 편차 유형 분류 →
  회귀 라우팅 테이블 적용
- 연속 2회 주의 = 경보로 상향 (만성 편차의 조기 포착)

## 2. 이중고리 학습 체계 (조직 학습 전문가)

### 2-1. Phase 회귀 라우팅 테이블 (표준)

| 편차 유형 | 판단 기준 | 고리 | 회귀 목적지 |
|---|---|:---:|---|
| 일정·실행 지연 | 과업 지연, 자원 일시 부족 — 목표·과제는 유효 | 단일 | **P5 내 조정** (일정 재배치·R 조정) |
| 과제 효과 미달 | 과업은 완료됐으나 KPI 미개선 — 과제 설계 결함 | 이중 | **P3·P4 재검토** (대안 교체·재판정) |
| 목표 체계 결함 | KR 자체가 부적절(측정 불가·오지표)·목표 간 상충 | 이중 | **P2 회귀** (목표 재정렬) |
| 환경 전제 붕괴 | 정책 급변·시장 구조 변화 — P1 진단의 전제 무효화 | 이중 | **P1 재진단** (환경분석 재수행) |

- 판정 주체: 협의체 (단일고리는 A 전결 가능, 이중고리는 협의체 의결)
- 회귀 시 해당 Phase 스킬을 [DATA] 블록과 함께 재실행 — 갱신된 출력이
  후속 Phase에 재전파됨을 명시

### 2-2. 가정 검증 계획 (체인 가정의 종착점)

- 원천: P2~P5 각 [DATA] 블록의 assumptions 전수 수집 (본 스킬 신규
  가정 포함)
- 각 가정에 배정: 검증 시점(즉시/마일스톤/분기) / 검증 방법(데이터
  확인·담당 부서 조회·실측) / 담당 / **오류 판명 시 회귀 Phase**
- 우선순위: 확신도 "하" + 틀릴 경우 영향 大 가정부터 조기 검증
- 검증 완료 가정은 [확정] 또는 [기각]으로 갱신 — 기각 시 라우팅 즉시 적용

### 2-3. AAR 자산화 규격 (4문 고정)

1. 의도한 것은 무엇이었나 (계획·목표치)
2. 실제로 일어난 것은 무엇인가 (실적·사건, 수치 기반)
3. 차이의 원인은 무엇인가 (단일고리/이중고리 구분하여 진단)
4. 다음에 무엇을 다르게 할 것인가 (구체 행동 1개 이상)
- 기록 시점: 중간 평가·경보 발동·컨틴전시 발동 시 의무
- 저장·공유: 사용자 조직의 문서 체계 지정 — 미확인 시 [가정] 라벨로
  표준 제안(공유 폴더 + 차기 계획 수립 시 필수 참조 규정)

## 3. 컨틴전시 플랜 (리스크 관리자)

### 3-1. 트리거 도출 순서 (고정 템플릿 금지)

1. **사업 고유 트리거 (우선)**: P5 risk_watch → P4 핵심 리스크·
   legal_flags → P1 위협(T) 요인 순으로 승계·구체화
2. **표준 3종 (최소 점검 세트)**: ①예산 삭감·핵심 인력 이탈
   ②규제·정책 기조 변경 ③기술 결함·구현 지연 — 고유 트리거와
   중복되면 통합
- 정식 모드 5~8건 / 약식 3~5건 권장

### 3-2. 트리거 필수 속성 (하나라도 없으면 실격)

- **정량 발동 조건**: "예산 ○% 이상 삭감 확정 시", "핵심 인력 ○명
  이탈 시", "고시 개정안 입법예고 시" — "예산이 부족해지면"류의
  모호 조건 금지
- **위험도**: 발생 가능성 × 영향 (상/중/하) + 근거 1줄
- **플랜 B**: 축소 수행 / 대체 경로 / 일시 중단 + 재개 조건 중 택일
  이상 구체화
- **의사결정권자**: 발동 선언 권한 1인(기능) — RACI의 A와 정합
- **사전 확보성**: 플랜 B에 드는 재원·인력·대체 공급처가 발동 전에 확보돼
  있는지 [확보]/[미확보] 표기. [미확보]면 확보 조치(예비비·예비 재원 편성,
  대체 공급처 사전 협약, 대체 인력 사전 지정)를 즉시 조치 또는 P5 선결 과업으로
  등록 — 발동 시점에 비로소 구해야 하는 수단만으로 된 플랜 B는 실격
- **소통 순서**: 발동 시 통지 대상·순서 (내부 → 이해관계자)

### 3-3. 복구·재개 규정

- 컨틴전시는 발동으로 끝나지 않는다 — 정상 복귀 조건과 복귀 후
  잔여 영향 평가(AAR 의무)를 함께 정의

## 4. 점검 모드 절차 (실적 데이터 제공 시)

1. 실적 vs 계획 편차 산출 — KPI별 달성률 표 ([실적] 라벨, 미제공
   지표는 "미제공·판정 보류")
2. 신호등 판정 (P5 기준 승계)
3. 편차 유형 분류 → 회귀 라우팅 테이블 적용
4. 조치 권고: 단일고리(구체 조정안) / 이중고리(회귀 Phase + 재실행
   시 갱신 대상 명시)
5. AAR 4문 기록 + 가정 검증 계획 갱신([확정]/[기각] 반영)

## 5. 토론 시 관점별 대표 지적 유형 (참고)

- 프로젝트 통제관: "주간 보고 4종은 과잉 통제다 — 실행 공수를
  잠식한다", "경보 판정 후 조치 주체가 없다", "중간 평가가 상위
  평가 마감 이후에 배치돼 실적 반영이 불가하다"
- 조직 학습 전문가: "전부 단일고리 시정뿐 — 전제를 수정하는 경로가
  없다", "확신도 '하' 가정이 검증 계획에서 빠졌다", "AAR이 성공
  사례만 기록하게 설계됐다"
- 리스크 관리자: "발동 조건이 정성적이라 아무도 발동을 선언하지
  못한다", "플랜 B가 '적극 대응'뿐이다", "복귀 조건 없이 중단만
  정의됐다"
