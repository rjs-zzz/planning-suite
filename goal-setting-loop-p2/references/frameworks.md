# 프레임워크 세부 작성 규칙 (Phase B 착수 시 로드)

## 1. Golden Circle (가치 정렬가)

- **Why (미션·존재 이유)**: 시한 없는 항구적 선언. "무엇을 한다"가 아니라
  "왜 존재하는가"로 서술. 공공기관은 설치법·정관상 설립 목적과 정합 필수
- **How (핵심가치·행동 원칙)**: 3~5개 이내. 명사형 키워드 + 1줄 정의.
  조직 구성원의 의사결정 기준으로 작동 가능한 수준까지 구체화
- **What (비전·지향점)**: 시한 있는 목표 상태(3~5년 권장). 달성 여부를
  사후 판별할 수 있는 서술 지향 — 판별 불가 표현은 KR로 보완
- 검증 질문: "이 비전이 달성되면 미션에 실제로 가까워지는가?",
  "경쟁·유사 기관의 문구를 그대로 바꿔 넣어도 성립하는가?(성립하면 실격)"

## 2. BSC 전략맵 (전략 맵 설계자)

### 2-1. 공공형 BSC (기본값 — 공공기관·비영리 조직)

인과 사슬 (하위 → 상위):

- **[최상위] 공공가치·미션 달성**: 설립 목적의 실현 정도
- **[관점 4] 고객·이해관계자**: 수혜자·지역사회·상급기관이 인식하는 가치
- **[관점 3] 재무 지속가능성**: 공공가치 창출을 지속할 재정 기반
  (목적이 아닌 제약·기반 관점으로 취급)
- **[관점 2] 내부 프로세스**: 가치 전달을 위한 핵심 업무 방식
- **[관점 1] 학습·성장**: 인적 역량·조직문화·정보 인프라

### 2-2. 표준형 BSC (선택 — 수익사업·영리 맥락 기획 시)

- 재무 → 고객 → 내부 프로세스 → 학습·성장 (재무 최상위)
- Phase A 계획 단계에서 안건 성격에 따라 택일하고 사유 1줄 명시

### 2-3. 인과관계 서술 규칙

- 각 관점의 전략목표는 반드시 상위 관점의 특정 목표를 지목하여 연결:
  "○○ 역량 강화(학습·성장) → ○○ 프로세스 혁신(프로세스) → ..."
- 연결 근거가 인과가 아닌 희망(correlation·기대)이면 토론에서 지적 대상
- 어느 상위 목표와도 연결되지 않는 고아 목표는 삭제 또는 재배치

## 3. OKR & SMART (목표 정량화 전문가)

### 3-1. 구조 규칙

- Objective: **3~5개 이내** (그 이상은 우선순위 부재로 간주)
- Key Results: Objective당 **2~4개**
- 시간 지평 구분: 미션(항구) / 비전(3~5년) / 전략목표(계획 기간) /
  연도 OKR — 산출물에 지평을 명기

### 3-2. KR 유형 이원화 (OKR·KPI 철학 충돌 방지)

- **[도전]**: 야심 목표. 70% 수준 달성도 성공으로 간주하는 stretch 지표
- **[필수]**: 달성 책임 목표. 100% 달성이 기준선인 commit 지표
  (경영평가 대응 지표, 법정 의무 지표는 원칙적으로 [필수])
- 유형을 표에 명기 — 도전 지표를 필수처럼 평가하는 오용 방지

### 3-3. KR 필수 속성 (하나라도 없으면 Phase C 측정 검증 탈락)

- 산식 (분자/분모 또는 측정 방법)
- 데이터 원천 (시스템·담당 부서·통계 출처)
- 기준선 (현재값 — 미확보 시 [가정] 라벨 + 확보 방법 명시)
- 목표치 + 목표 연도
- 측정 주기 (월/분기/반기/연)

### 3-4. SMART 점검

- Specific / Measurable / Achievable / Relevant / Time-bound 5항목을
  KR별로 통과 여부 확인. 미통과 항목은 수정 후 재확인
- Achievable 판정 근거: Phase 1의 내부 역량 분석(3C·VRIO) 결과 인용

## 4. 토론 시 관점별 대표 지적 유형 (참고)

- 가치 정렬가: "이 목표는 Why와 무관한 관성 사업이다",
  "비전 문구가 타 기관과 교체 가능하다"
- 전략 맵 설계자: "이 인과 연결은 기대일 뿐 메커니즘이 없다",
  "학습·성장 관점이 비어 있어 지속가능성이 없다"
- 목표 정량화 전문가: "이 KR은 활동량 지표이지 성과 지표가 아니다",
  "기준선 없이 목표치만 있어 달성 난이도를 판단할 수 없다"
