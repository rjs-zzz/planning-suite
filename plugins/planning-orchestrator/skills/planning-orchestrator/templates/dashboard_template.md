# 관제 대시보드 템플릿 (Phase D — 이 구조를 그대로 준수)

※ 매 관제 턴마다 출력. [ORCH-STATE] 블록은 어떤 경우에도 누락 금지.
※ 자동 관통 모드의 중간 Pass 턴은 2절 판정 1줄 + 4절 + [ORCH-STATE]만 출력해도 된다.
※ 통합 모드는 산출·검증 주체가 같은 모델임을 2절 하단에 1줄 적는다.

---

## 【 기획 오케스트레이션 대시보드 】

### 1. 진행 상황 (State Track)
○ **안건**: [기획 주제] / **Cycle**: [n] / **모드**: [분산·통합 / 단계별 승인·자동 관통]

```
[P1 진단]  ▣ 완료 (Approved YYYY-MM-DD)
[P2 목표]  ▣ 완료 (Approved YYYY-MM-DD)
[P3 전략]  ▨ 진행 중 (Active)
[P4 검토]  ▢ 대기 (Locked)
[P5 실행]  ▢ 대기 (Locked)
[P6 환류]  ▢ 대기 (Locked)
```
※ 중간 진입 시 건너뛴 단계는 "▷ 생략 [가정]" 표기

### 2. Q-Gate 검증 보고 [블록 접수 시]
○ **검증 대상**: [DATA-P○-OUTPUT] ([접수 일시 기준])
○ **판정**: **Pass / Hold / Rollback**

| 검증 항목 | 결과 | 비고 |
|---|:---:|---|
| 스키마 (필수 필드) | ○/△/✕ | [결손 필드 목록] |
| 이월 플래그 (가정·미해결 건) | ○/△/✕ | [유실 항목] |
| 상호 참조 정합 | ○/△/✕ | [불일치 쌍] |
| 회귀 신호 | ○/✕ | [탐지 내용] |

○ **Hold 시 — 보완 요구 목록**: [항목별 — 재실행 불요, 보완 후 재접수]
○ **Rollback 시 — 회귀 지시서**:
- 회귀 목적지: P○ / 수정 대상: [필드·항목]
- 재검토 목록: [후속 Phase·항목 단위 — 선별]
- 무영향 확정: [재실행 불요 항목]
- 사유: [1~2줄]

### 3. 차기 브리핑 패키지 [Pass 시]
○ **차기 단계**: P○ ([스킬명]) — [분산 모드: 새 세션에서 아래 패키지 붙여넣기 / 통합 모드: 즉시 착수]
○ **주의 논점** (handoff 기반): [3~5개]
○ **동봉 블록**: [DATA-P○-OUTPUT] 원문 (무수정) + 이월 플래그 요약

### 4. 이월 현황 (Carried Flags)

| 구분 | 건수 | 내역 요약 |
|---|:---:|---|
| 가정 누계 (P2~) | ○건 | [확신도 하 건 우선 표기] |
| 법률 미해결 | ○건 | |
| 상충·조정 대기 | ○건 | |

# [ORCH-STATE] (상태 원장 — 매 턴 필수 출력)

세션 간 상태 복원용. 사용자는 차기 관제 요청 시 이 블록을 붙여넣는다.

```markdown
# [ORCH-STATE]
## meta
- subject: [안건] / cycle: [n] / updated: YYYY-MM-DD
- mode: [분산/통합] · [단계별 승인/자동 관통] / entry: [진입 Phase]

## phases
- P1: Approved(날짜) | P2: Approved(날짜) | P3: Active
- P4: Locked | P5: Locked | P6: Locked
- skipped: [생략 단계 — 없으면 "없음"]

## carried_flags
- assumptions: [A1(P2)·A2(P3)... — 요지·확신도 압축, 누계 ○건]
- legal_open: [미해결 건 요지]
- conflicts_open: [판정 대기 건]
- inputs_missing: [미확보 자료 묶음 A~G — 없으면 "없음"]
- scan_log: [Phase별 탐색 주제·검색일·반영한 T번호 — 재탐색 방지용, 없으면 "없음"]

## gate_log
- [날짜] P2 게이트: Pass / [날짜] P3 게이트: Hold→보완 재접수 Pass

## rollback_log
- [날짜] P4→P3 회귀: [사유 1줄 | 재검토 범위 | 완료 여부]
- 없으면 "없음"

## next_action
- [차기 단계·필요 입력 1줄]
```
