# 예시 1 — P2 목표 체계 산출물 (`goal-setting-loop-p2`)

> 실제 실행 시 나오는 산출물의 형태. 조직·수치는 모두 가상이다.
> 핵심은 문서 말미의 `[DATA-P2-OUTPUT]` 블록 — 이 블록이 P3 스킬의 입력이 된다.

---

## 사용자 입력

```
우리 기관(한국○○진흥원, 직원 180명) 3개년 중장기 목표 체계 잡아줘.
환경분석은 아직 없고, 주무부처가 디지털 전환과 지역 균형발전을 강조하고 있어.
```

---

## 산출물

## 【 한국○○진흥원 3개년 목표 체계 (2027~2029) 】

### 1. 미션·비전

○ **미션**: 지역 산업의 기술 자립을 지원해 국가 균형발전에 기여한다.
○ **비전(2029)**: 지역 중소기업이 가장 먼저 찾는 기술지원 기관
○ 비전 판별 지표: 지역 중소기업 재이용률 **45% → 65%**

### 2. 전략 목표 (공공형 BSC — 공공가치 최상위)

| 관점 | 전략목표 | 대표 지표 | '26 실적 | '29 목표 |
|---|---|---|---|---|
| 공공가치 | SO1. 지역 기술격차 완화 | 수혜기업 기술자립도 | 52점 [추정] | 70점 |
| 고객 | SO2. 이용자 재방문 구조 확립 | 재이용률 | 45% | 65% |
| 내부 프로세스 | SO3. 지원 절차 디지털 전환 | 온라인 처리 비중 | 30% | 85% |
| 학습·성장 | SO4. 기술인력 역량 고도화 | 전문자격 보유율 | 22% | 40% |

### 3. OKR 전개 (1차년도)

○ **O1. 지역 중소기업이 반복해서 찾는 지원 체계를 만든다** (SO2 연계)
  - KR1-1: 재이용률 45% → 52%
  - KR1-2: 지원 완료 후 30일 내 후속 상담 연결률 0% → 60%
  - KR1-3: 평균 처리기간 21일 → 14일
○ **O2. 신청부터 정산까지 온라인으로 끝난다** (SO3 연계)
  - KR2-1: 온라인 처리 비중 30% → 55%
  - KR2-2: 종이 제출 서식 42종 → 15종
○ **O3. 현장 기술지원 인력의 전문성을 끌어올린다** (SO4 연계)
  - KR3-1: 전문자격 보유율 22% → 28%
  - KR3-2: 연 40시간 이상 기술교육 이수율 35% → 70%

### 4. 지표 검증

○ **선행/후행 균형**: 후행 3(재이용률·자립도·보유율) / 선행 5(후속 연결률·
  처리기간·온라인 비중·서식 수·교육 이수율) — 선행 지표 우세, 적정
○ **통제 가능성**: KR 8건 모두 기관 자체 통제 범위. 외부 변수 의존 KR 없음
○ **[신규] 라벨**: KR1-2, KR2-2는 현재 측정 체계 없음 — 1분기 내 측정 기반
  구축이 선행 조건

### 5. 확인 필요 사항·가정

| 라벨 | 가정 | 확신도 | 틀릴 경우 영향 |
|---|---|:---:|---|
| A1 | 기술자립도 52점은 유사 기관 평균에서 추정 | 하 | 기준선 오류 시 SO1 목표치 전면 재산정 |
| A2 | 환경분석 미수행 — 외부 위협 요인 미반영 | 중 | P1 수행 후 SO 구성 변동 가능 |
| A3 | 3개년 예산 증가율 연 3% 이내 | 중 | 긴축 시 SO3 투자 규모 조정 |
