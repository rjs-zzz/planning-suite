# 예시 3 — 통합 모드의 입력 점검 (`planning-orchestrator`)

> 계획서 전체를 한 세션에서 만들 때, 실행 전에 무엇을 한 번에 요청하는지 보여주는 형태 예시다.
> 조직·수치는 가상이다.

---

## 1. 사용자 요청

> planning-orchestrator로 우리 진흥원 3개년 발전계획 만들어줘. 작년 경영실적 보고서 첨부할게.

## 2. 스킬의 첫 응답 — 운영 계획 + 자료 요청 1회

```
## 【 기획 오케스트레이션 개시 】
○ 안건 요지: 한국○○진흥원 3개년 발전계획 (2027~2029)
○ 진입 Phase 판별: 환경분석·목표 체계 없음 → P1부터
○ 규모: 정식 (기관 단위, Phase 6개)
○ 권장 운영: 통합 모드 + 단계별 승인
○ 예상 흐름: P1 ▢ → P2 ▢ → P3 ▢ → P4 ▢ → P5 ▢ → P6 ▢

○ 입력 현황: 준비도 부분 | 확보: 주제·조직·기간, B 실적(경영실적 보고서) | 미확보: A·C·D·E·F·G
○ 있으면 올려 주세요 (없어도 진행합니다)
  - A 방침 — 현행 미션·비전, 상위 계획 → 없으면 신규 수립으로 가정
  - C 현행 사업 목록 → 없으면 '줄이거나 없앨 사업'은 일반 관행 기준 가정
  - D 재무 — 예산서, 가용 예산·인력 상한 → 없으면 타당성 검토는 금액 없이 등급 판정, 총량 판정 보류
  - E 조직도·고정 일정 → 없으면 담당은 '기획 기능' 같은 역할 명칭으로 표기
  - F 적용 법령·내부 규정 → 없으면 일반 법령만 식별하고 [확인 필요] 표기
  - G 기존 점검 회의체 → 없으면 표준 3층 평가 체계로 설계
  ※ 개인정보·대외비는 가리고 올려 주세요.

이 계획으로 진행할까요?
```

## 3. 사용자 답

> 미션·비전 문서랑 예산서 올릴게. 나머지는 없이 진행해.

## 4. 이후 — 다시 묻지 않는다

- 각 Phase는 착수할 때 자기가 쓰는 묶음의 확보 여부를 1줄로 밝히고 그대로 진행한다.
  예: "P5 착수 — E 조직·일정 미확보: 담당은 기능 역할 명칭, 고정 일정은 표준 캘린더 [가정]"
- 상태 원장에 미확보 묶음이 남아 세션이 바뀌어도 이어진다.

```markdown
# [ORCH-STATE]
## carried_flags
- inputs_missing: C·E·F·G
```

- 사용자가 나중에 조직도를 주면 E를 쓰는 P5만 다시 돌리면 된다 — 전체를 다시 하지 않는다.
