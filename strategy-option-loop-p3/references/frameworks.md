# 프레임워크 세부 작성 규칙 (Phase B 착수 시 로드)

## 1. TOWS 실행과제化 (전략 조합가)

### 1-1. 기존 전략방향 심화 절차 (기본 — Case 1/2)

- Phase 1/2에서 승계한 SO/WO/ST/WT 전략방향 각각에 대해:
  1. 전략방향 1개 → 실행 과제 1~3개로 분해
  2. 각 과제에 3요소 명시: **무엇을**(사업 내용) / **어떻게**(추진 방식) /
     **어느 규모로**(개략 자원·기간)
  3. 근거 연결 표기: "S2×O1 → [과제명]" 형식으로 원천 추적 가능하게 기록
- 유형별 과제 성격:
  - SO(기회 선점형): 공격적 확장 과제 — 강점 자산의 신규 활용처
  - ST(위협 극복형): 방어·전환 과제 — 강점으로 위협을 기회화
  - WO(약점 보완형): 역량 확충 과제 — 외부 기회·자원으로 약점 상쇄
  - WT(방어/철수형): 축소·리스크 관리 과제 — ERRC의 E·R과 연동

### 1-2. 신규 TOWS 매칭 (Case 3 한정)

- 사용자 제공 정보로 간이 S/W/O/T 각 3개 이내 도출 후 교차 매칭
- 간이 도출임을 [가정] 라벨로 명시, env-scanning-loop-p1 후행 수행 권고 병기

## 2. 포트폴리오 매트릭스 (포트폴리오 설계자)

### 2-1. 공공가치·실행역량 매트릭스 (기본값 — 공공기관·비영리 조직)

| 구분 | 실행역량 高 | 실행역량 低 |
|---|---|---|
| **공공가치 高** | 핵심 추진 (즉시 착수) | 역량 확충 후 추진 (파트너십·단계화) |
| **공공가치 低** | 효율화·현상 유지 | 정리 검토 (ERRC의 E·R 후보) |

- 공공가치: 미션 기여도 + 수혜자 규모 + 정책 정합성 종합 판단
- 실행역량: 인력·예산·기술·조직 수용성 (Phase 1의 3C·VRIO 결과 인용)
- 사분면 판정 근거를 각 과제에 1줄 기록

### 2-2. Ansoff 성장 벡터 (병행)

- 기존 서비스×기존 수혜자(침투·고도화) / 신규 서비스×기존 수혜자(개발) /
  기존 서비스×신규 수혜자(확장) / 신규 서비스×신규 수혜자(다각화)
- 4개 벡터 중 공백 벡터가 있으면 후보 과제 추가 검토 — 단, 공백을
  채우기 위한 억지 과제 생성 금지 (공백 사유 명시로 대체 가능)

### 2-3. BCG 매트릭스 (선택 — 수익사업·시장 경쟁 맥락 한정)

- 시장성장률×상대점유율 논리는 시장 경쟁 사업에만 유효
- 적용 시 계획 단계에서 적용 사유 1줄 명시. 시장 논리로 판단할 수
  없는 공공 고유 기능(법정 필수사업 등)에는 적용 금지 — Dog 판정
  오용 방지

## 3. Blue Ocean ERRC (혁신 설계가)

- **Eliminate (제거)**: 목표 기여가 소멸된 관행 사업 — 중단 시 영향과
  이해관계자 저항 예상 병기
- **Reduce (감소)**: 산출 대비 과투입 사업 — 축소 폭(%)과 절감 자원 추정
- **Raise (증가)**: 차별적 우위 원천 — 집중 투자 시 KR 개선 기대치 추정
- **Create (창조)**: 미충족 수요 대응 신규 과제 — 국내외 유사 사례
  존재 여부 표기 (사례 미확인 시 [추정] 라벨)
- **자원 균형 원칙**: E·R에서 확보되는 자원(예산·인력) 추정 총량이
  R·C 소요 추정 총량과 대비 가능하도록 양쪽 모두 개략 수치 제시
- 기존 사업 목록 미제공 시: 동종 기관 일반 관행 기준으로 E·R 후보를
  [가정] 도출하고, 실제 목록 확인 후 교정 필요를 명시

## 4. 예비 우선순위 간이 스코어링 (수렴 단계)

- 산식: **목표 기여도(1~5) × 실행 가능성(1~5)** = 총점(1~25)
- 목표 기여도 기준: 기여 Objective 수·핵심 KR 직결 여부·기여 크기
- 실행 가능성 기준: 자원 확보 전망·조직 수용성·법규 제약·선례 유무
- 각 점수에 근거 1줄 필수 — 무근거 점수 부여 금지
- 동점 시 보조 기준: 시급성(정책 시한·상위 평가 주기) > 파급 범위
- **한계 명시 의무**: "본 순위는 발굴 단계의 예비 순위이며, 확정 선정은
  차기 Phase의 정밀 평가(비용·리스크·시뮬레이션)를 거쳐야 함"을
  표 하단에 고정 표기

## 5. 토론 시 관점별 대표 지적 유형 (참고)

- 전략 조합가: "이 과제는 어느 S×O 조합에서도 도출되지 않는 돌출
  아이디어다", "전략방향을 그대로 복사했을 뿐 실행 수준 분해가 없다"
- 포트폴리오 설계자: "핵심 추진 사분면에 과제가 몰려 자원 총량을
  초과한다", "혁신 과제가 전무해 중장기 성장 동력이 없다"
- 혁신 설계가: "제거·축소 없이 신규만 쌓아 실행 불가능한 목록이다",
  "Create 과제가 기존 사업의 명칭 변경에 불과하다"
