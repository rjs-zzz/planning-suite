# 판정 기준·프레임워크 세부 규칙 (Phase B 착수 시 로드)

## 1. 3축 점수 및 등급 매핑 (자의적 등급 방지)

### 1-1. 3축 점수 (각 1~5점, 근거 1줄 필수)

- **경제성 (재무/비용 검증가)**:
  5=편익이 비용을 명확 상회(B/C>1.2 또는 정성적 압도) / 4=상회 추정 /
  3=균형·불확실 / 2=비용 우위 추정 / 1=명백한 비용 초과
- **정책·법률 적합성 (정책/법률 감사관)**:
  5=정책 정합+법적 장애 없음 / 4=경미한 절차 보완 필요 /
  3=규정 해석 쟁점 존재(법무 검토 필요) / 2=저촉 가능성 中 이상 /
  1=저촉 가능성 高·정책 역행
- **자원 실행성 (자원 제약 분석가)**:
  5=현 자원으로 즉시 가능 / 4=경미한 보강으로 가능 /
  3=상당한 확보 노력 필요 / 2=외부 의존 과다·확보 불투명 /
  1=현실적 확보 불가

### 1-2. 등급 매핑 (합산 3~15점)

| 등급 | 합산 점수 | 조건 |
|:---:|:---:|---|
| **S** | 13~15 | 전 축 4점 이상 |
| **A** | 10~12 | 1점 축 없음 |
| **B** | 7~9 | 1점 축 없음 |
| **C** | 3~6 또는 1점 축 존재 | — |

### 1-3. 판정 4단계

- **Pass**: S·A 등급 + 하드 게이트 통과 → 실행계획 단계 직행
- **조건부 Pass**: B 등급 또는 특정 축 보완으로 A 도달 가능 —
  **이행 조건**(무엇을·언제까지)을 반드시 명기
- **Hold**: C 등급 중 보완 여지 존재 — 재검토 트리거(어떤 조건이
  충족되면 재상정하는지) 명기
- **Drop**: 하드 게이트 탈락(위법 확실) 또는 보완 불가 — 사유 보존
- **하드 게이트**: 적법성 축 1점 + 저촉 가능성 高 확인 시 타 축 무관
  즉시 Drop. 단, 확정 판단이 아니므로 "법무 자문으로 뒤집힐 경우
  재상정 가능"을 병기

## 2. CBA·NPV·B/C 운용 규칙 (재무/비용 검증가)

### 2-1. 분석 모드별 산출 한계 (엄수)

- **정밀 모드**: NPV·B/C 실계산. 필수 명시: 분석 기간, 할인율(적용값과
  출처 — 기재부·KDI 예비타당성 지침의 사회적 할인율을 기본 참조하되
  적용 시점 기준 값을 [확인 필요] 라벨로 검증 유도), 비용·편익 항목별
  산출 근거
- **개산 모드**: 점 추정 금지, **범위 추정**(예: "연 ○~○백만원 [추정]")만
  허용. 범위 산정 논리 1줄 필수
- **정성 모드**: 수치 산출 전면 금지. 산출물은 ①비용 항목 목록(초기/
  운영 구분) ②편익 항목 목록(재무적/비재무적 구분) ③정성 등급 판정
  ④"예타 수준 정밀 분석 필요" 명시의 4요소
- 공통: 모드 간 무단 상향 금지 — 데이터가 없는데 수치가 나오면 오류

### 2-2. 공공 편익의 취급

- 비재무 편익(건강 성과, 접근성, 형평성)은 화폐화를 강제하지 않는다 —
  화폐화 시도 시 방법론(지불의사, 회피비용 등)과 한계를 병기
- 편익의 이중 계산 금지 (동일 효과를 재무·비재무 양쪽 산입 금지)

## 3. 공공가치 진단 (정책/법률 감사관)

- Mark Moore 전략적 삼각형 3문 진단:
  1. **공공가치**: 이 과제가 창출하는 공적 가치는 무엇인가 (수혜자·크기)
  2. **정당성·지지**: 정부 정책·이사회·지역사회의 지지를 확보할 수
     있는가 (정책 문서·상위 계획과의 정합 근거)
  3. **운영 역량**: 조직이 실제로 전달할 수 있는가 (자원 축과 교차 확인)
- 3문 중 1개라도 공백이면 조건부 이하로 판정

## 4. 법령·감사 리스크 플래그 규칙 (정책/법률 감사관)

- 플래그 형식: [법령명 조항 | 쟁점 1줄 | 저촉 가능성 高/中/低 |
  법무 검토 필요 여부]
- 원문 확인 수단(법령 MCP·국가법령정보센터 웹검색) 가용 시 조항 원문
  대조 후 인용, 불가 시 [확인 필요] 라벨 — **기억에 의한 조문 인용 금지**
- 감사 리스크는 별도 행: [유형(예산/계약/절차/이해충돌) | 시나리오 1줄 |
  예방 통제 방안]

## 5. 5대 자원 검증 (자원 제약 분석가)

- 과제별 표: 인적/물적/재무/기술/파트너십 × (소요 추정 | 확보 경로 |
  갭 | 리스크)
- RDT 관점 추가 점검: 외부 의존 자원(위탁·협력기관·단일 공급자)의
  의존도와 통제력 상실 지점 — 의존도 高 자원은 대체 경로 1개 이상 제시
- **포트폴리오 총량 대사**: Pass·조건부 과제의 자원 소요 합산표 작성 →
  가용 총량(P3 ERRC 확보분 포함) 대비. 초과 시 처리 순서:
  ① 조건부 과제의 단계화(연차 분산) → ② Hold 전환 → ③ 그래도 초과 시
  초과 사실을 명시하고 Phase 5에 조정 과제로 인계

## 6. 간이 민감도 규칙

- 대상: 등급 경계(±1점로 등급 변동) 과제 + Pass 중 자원 의존도 高 과제
- 시나리오: 비용 +30% / 편익(또는 기여 추정) −30% 각각 적용
- 표기: "민감도: 유지 / 반전(→B, 조건부 전환)" 1칸으로 압축

## 7. 토론 시 관점별 대표 지적 유형 (참고)

- 재무/비용 검증가: "편익 추정이 낙관 단일 시나리오다", "운영비를
  누락하고 초기 투자만 계산했다", "재원 경로가 '국고 확보 추진'뿐이다"
- 정책/법률 감사관: "수의계약 사유가 성립하지 않는다", "개인정보 처리
  근거 조항이 없다", "이사회 의결 사항인데 절차 계획이 없다"
- 자원 제약 분석가: "전담 인력 산정 없이 '기존 인력 활용'으로
  처리했다", "단일 외부 기관 의존인데 대체 경로가 없다", "과제 3개가
  동일 부서 동일 시기에 몰려 있다"
