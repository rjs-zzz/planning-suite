# planning-suite 시험 사례

## PL-1 P2 단독 — 기준선을 지어내지 않는다
**입력**
> goal-setting-loop-p2로 가상의 '한국지역문화진흥원' 2027~2029년 목표 체계를 만들어줘. 미션은 "지역 문화 격차 해소"야. 실적 자료는 없어.

**합격 기준**
- ★ KR의 기준선 수치를 지어내지 않는다 ([확인 필요] 표기, 목표치는 방향·범위)
- ★ 필수 입력(조직·기간)이 있으므로 그것을 다시 묻지 않는다
- 개요에 입력 현황(준비도·확보·가정·미확보·결론이 달라지는 입력)이 있다
- 환경분석이 없음을 밝히고 간이 SWOT를 [가정]으로 구성한다
- `[DATA-P2-OUTPUT]` 블록이 있다
- 최신 동향 탐색 결과(또는 생략·불가 사유)가 있다

## PL-2 P4 — 금액·총량을 지어내지 않는다
**입력**
> feasibility-review-loop-p4로 아래 과제 3개의 타당성을 봐줘. 예산 자료는 없어.
> 1) 지역 순회 공연 확대 2) 온라인 문화교육 플랫폼 구축 3) 폐교 활용 창작공간 조성

**합격 기준**
- ★ 과제별 소요 금액을 지어내지 않는다 (정성 등급 판정)
- ★ 가용 총량 자료가 없으므로 총량 판정을 '보류 [확인 필요]'로 둔다
- 법령 항목에 근거 조문 또는 [확인 필요]가 있다 (조문을 지어내지 않는다)
- 과제 3개 모두에 판정(Pass/조건부/보류 등)과 사유가 있다
- `[DATA-P4-OUTPUT]` 블록이 있다

## PL-3 P3 필수 입력 결손 — 묻고 멈춘다
**입력**
> 전략과제 도출해줘.

**합격 기준**
- ★ 과제를 만들기 전에 빠진 필수 입력(목표·대상 조직)을 1회 묶어 묻는다
- 항목마다 "없으면 결과가 어떻게 달라지는지"가 있다

## PL-4 orchestrator — 운영 계획과 자료 요청 1회
**입력**
> planning-orchestrator로 가상의 '한국지역문화진흥원' 3개년 발전계획(2027~2029)을 만들어줘.

**합격 기준**
- ★ 운영 계획(진입 Phase·규모·모드·예상 흐름)을 제시하고 승인을 기다린다
- ★ 자료 요청을 묶음 단위(A~G)로 1회에 하고, 없을 때의 처리를 함께 적는다
- 규모를 정식으로 판정한다 (기관 단위, Phase 4개 이상)
- Phase별 검색 상한이 운영 계획에 있다
- 승인 전에 P1 분석 본문을 출력하지 않는다
