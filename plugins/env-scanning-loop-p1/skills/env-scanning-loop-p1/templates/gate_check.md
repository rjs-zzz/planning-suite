# 게이트 판정표 템플릿 (매 검증 시 필수 출력)

## 【 정합성 게이트 판정표 — Loop N/3 】

○ **반례 탐색 결과** (판정 전 의무 수행)
 - PEST: (이 분석이 틀렸다면 가장 취약한 지점 1개 이상)
 - 3C/5F: (동일)
 - VRIO: (동일)

○ **델타 분석 요약** (정밀 모드만): 신규/누락 ○건 / 판정 상이 ○건 /
  오염 의심 플래그 여부 및 조치

| 게이트 | 판정 | 판정 사유 (구체적) | 반려 시 보완 지시 |
|---|---|---|---|
| **G1 논리 인과** | Pass/Fail | PEST→3C→VRIO 인과 사슬 점검 결과 | (Fail 시) 대상 에이전트 + 보완 항목 특정 |
| **G2 데이터 신뢰성** | Pass/Fail | 근거 등급·출처 점검 결과, 추정 둔갑 여부 | (Fail 시) 재검증 대상 수치·출처 특정 |
| **G3 MECE** | Pass/Fail | 이해관계자·분석 축 누락/중복 점검 결과 | (Fail 시) 추가 분석 대상 특정 |

○ **종합 판정**: 통과 → Phase D 진행 / 반려 → (에이전트명) 국소 재수행
○ **누적 Fail 이력**: Loop 1: ○○ / Loop 2: ○○ (해소 여부 병기)
○ **Loop 3 초과 시**: 강제 채택 안 + 미해결 항목 → "잔여 리스크" 절 이관 명기
