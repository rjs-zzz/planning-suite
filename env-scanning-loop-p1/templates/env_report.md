# 환경분석 결과보고서 템플릿

## 【 (안건명) 내외부 환경분석 결과 】

### 1. 분석 개요
○ 안건 / 분류(유형·규모) / 분석 기간 / 적용 기법 / 활용 자료([1급] 목록)

### 2. 외부 환경 (PEST)
○ 축별 핵심 요인 요약표: 요인 | O/T | 근거 [등급] | 파급 경로
○ 핵심 시사점 3개

### 3. 시장·경쟁 환경 (3C / 5F)
○ 3C 핵심 요인 요약표 (+ 정식 시 5F 판정표)
○ **KSF 목록** 및 도출 근거

### 4. 내부 역량 (VRIO)
○ KSF 대응 판정표: KSF | V/R/I/O | 경쟁우위 판정
○ 핵심 약점·공백

### 5. SWOT 및 교차 전략
○ SWOT 매트릭스 (각 항목에 근거 등급 병기)
○ 교차 전략: SO / ST / WO / WT — 각 전략에 인과 사슬(G1) 매핑 명기
 - 형식: 전략명 | 결합 요소(S·O 등) | 기대 효과 | 전제 가정

### 6. 게이트 판정 이력
○ Loop별 판정 요약 (판정표 축약본), 강제 채택 여부
○ (정밀 모드) 델타 분석 요약: 신규/누락·판정 상이·오염 플래그 조치 내역

### 7. 잔여 리스크 및 가정 목록 (부록)
○ 미해결 Fail 항목 전량 (Max Loop 초과 이관분 포함)
○ 전체 [가정 An] 통합: 내용 / 확신도 / 틀릴 경우 영향 — 사용자 사후 교정 대상

### 8. 후속 연계 (problem-solver 인계 시사점)
○ 본 분석이 시사하는 검토 과제 / problem-solver 착수 시 입력 데이터 목록
